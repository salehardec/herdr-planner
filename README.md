# Herdr Planner

Отдельный дашборд доски **herdr-projects** — теперь трёхмерный мир. Координатор
(«Бог») в центре, проекты — вселенные, задачи — планеты, агенты — спутники.
Работает сам по себе: herdr (TUI) и herdr-gpui не нужны, данные и команды идут
напрямую в `herdr-projects`.

Документ мира: [`design/world.md`](design/world.md). Плоский макет панели
остаётся историей: [`design/herdr-planner.html`](design/herdr-planner.html).

```
        · вселенная ·        дела божьи  ◉ Бог ◉ чат        · вселенная ·
      планеты, спутники        (список)   (свет)  (консоль)    планеты, связи
```

## Установка

Нужны:

- Rust (сборка; если `cargo` стоит через mise, `scripts/install.sh` сам вызовет
  `mise x rust@stable -- cargo`);
- `herdr-projects` в `PATH` (доска);
- для значка в панели — Omarchy, `jq`, `systemctl --user`;
- для файлов — `yazi` и `xdg-terminal-exec`;
- для проверок — Node 22+ и Chromium (WebGL в headless идёт через SwiftShader).

Скрипт собирает **вне репозитория** — это важно, если репозиторий на NTFS, где
собранные файлы не запускаются:

```
~/.cache/herdr-planner/target
```

```sh
git clone <repo> herdr-planner
cd herdr-planner
scripts/install.sh
```

`scripts/install.sh` собирает release, ставит `~/.local/bin/herdr-planner` и
`herdr-planner-open`, включает `systemd --user` службу, ставит `.desktop`, значок,
ярлык Hyprland и значок в панели Omarchy. Без пароля служба слушает только
`127.0.0.1:7117`.

Обновление — тот же `scripts/install.sh`. Удаление:

```sh
scripts/install.sh uninstall
scripts/install.sh status
```

Состояние (`~/.local/state/herdr-planner`: журнал, чат, дела божьи) и
`~/.config/herdr-planner/config.toml` при удалении сохраняются.

### Значок и окно

Значок в панели Omarchy открывает **отдельное окно-приложение** (Chromium app
window, 1280×940), а не вкладку. То же делает ярлык «Herdr Planner» и
`herdr-planner-open`. Окно опознаётся по app-id в отдельном профиле Chromium;
вкладки и обычные окна браузера им не считаются.

## Мир

- **Бог** — Координатор в центре: звезда цвета акцента темы, ореол, свет. Над ним
  талисман и счётчик «ждут тебя: N». Работает — ореол пульсирует; показывает
  диалог — жёлтый ореол и «диалог»; ошибка — красный.
- **Чат** — консоль Координатора справа-ниже звезды (DOM, привязанный к точке
  мира). Крутится и приближается со сценой, но остаётся читаемым и вводимым.
- **Дела божьи** — список идей слева-ниже звезды: добавить, поправить двойным
  щелчком, убрать; **перетащить в вселенную** — в проекте создаётся задача
  (`herdr-projects add <текст> --repo <проект>`), и на орбите появляется планета.
  Список хранится на сервере (`todo.json`) и один для всех клиентов.
- **Вселенная** — проект: солнце, орбиты, планеты. Угол на кольце вокруг Бога
  запоминается, проект не прыгает. «Тихие» проекты — туманности на внешнем кольце.
- **Планета** — задача. Радиус и вид зависят от статуса, орбита — от номера;
  агент летит спутником (форма по программе). Подпись — выноска сбоку-сверху,
  она не накрывает планету: в общем виде остаются точки-значки, во вселенной —
  ключ и значок. Полный текст — не больше чем у одной планеты (выбранной,
  наведённой или единственной ближайшей при очень близкой камере), поэтому
  приближение не даёт стопку полных подписей. Если чипы пересекаются, менее
  срочный понижается до значка.
- **Связи** — зависимости `after`: пунктир от предшественника к ждущей, бегущая
  точка показывает направление; сделанный предшественник — бледная линия.
  Ссылка на архивную задачу рисуется от далёкой звезды с её тегом, но хранит id:
  следующие правки связей не ломаются.
- **Запросы к человеку** — маяк у планеты и счётчик у Бога; «Фокус» показывает
  полный вопрос, разрешение, план, попытки или диалог на экране агента.

Цвета — из текущей темы Omarchy (`colors.toml`), без перезагрузки. Статус
различим не только цветом: свой значок, подпись и форма планеты.

### Навигация и клавиши

| Клавиши | Что делают |
|---|---|
| ЛКМ / колесо / ПКМ | вращение, зум, панорама |
| `← → ↑ ↓` | орбита камеры |
| `+` / `−` | ближе / дальше |
| `0` / `Home` | общий вид |
| `Enter` | подлететь к выбранной планете |
| `Tab` / `Shift+Tab` | следующая / предыдущая планета по срочности |
| `1–9` | N-й запрос из «Ждёт тебя» |
| `[` / `]` | предыдущая / следующая вселенная |
| `N` | навигатор мира (список; он же запасной вид без WebGL) |
| `F` | панель «Фокус» |
| `J` / `W` | журнал / «Ждёт тебя» |
| `A` | архив |
| `L` | режим связи: тянуть линию мышью |
| `Shift` + перетащить | связь без режима `L` |
| `T` | дела божьи |
| `/` | в чат |
| `?` | подсказка |
| `Esc` | закрыть панели, выйти из режима, общий вид |

Клик по планете выбирает её и подлетает; по солнцу проекта — к вселенной; по
Богу — к центру; двойной клик по пустоте — общий вид. HUD-крошки
`Мир › alpha › ALP-7` возвращают на уровень.

### Связи

Потяни от планеты, которая **будет ждать**, к той, что раньше (внутри вселенной
или между вселенными). Уходит `herdr-projects after <ждущая> <та>`; успех — тост с
«Отменить», отказ доски (круг, неизвестная задача) — её текст, связи нет.
Снятие — в «Фокусе» у задачи или кликом по линии.

### Запросы к человеку

Справа в «Фокусе» — блок «Запрос»: полный текст, затем ответ.

- вопрос — поле «Ответить» (`tell`);
- разрешение — «Разрешить» / «Запретить» подставляют текст в поле (его можно
  поправить) и отправляют `tell`; для готовой к одобрению ещё `approve` /
  `approve --anyway` (два клика, см. ниже);
- вход — «Написать агенту» / «Остановить», логин — на машине с доской;
- план — полный текст, «Одобрить план» (два клика) или «Вернуть с замечаниями»;
- выбор попытки — карточки A/B/C с агентом, результатом, diff и отчётом → `pick`;
- лимит — «Продолжить» (`retry`) / «Завершить как есть» (`finish`);
- упала — `retry`, `fix`, `finish`, `stop`;
- ревьюеру нужен ты — «Показать экран» и клавиши через `herdr agent send-keys`
  в панель ревьюера `sw-<repo>-<n>-r`, а не работника;
- Координатор — только нумерованные/буквенные варианты **после** вопроса
  кнопками в чате (маркированные объяснения не становятся ответами); диалог на экране —
  плашка в чате с текстом `herdr agent read` и клавишами; без herdr — честное
  «ответить можно только в окне herdr».

Счётчик «Ждут тебя» есть в HUD и на панели `W`. Уведомления (браузерные и
короткий звук) по умолчанию выключены; переключатель в HUD. В заголовке вкладки —
`(N) Herdr Planner`. У удалённого клиента всё то же: ответы идут через сервер.

## Задачи и действия

Данные:

- `herdr-projects list --all --json` — задачи и архив (`archivedAt`);
- `herdr-projects list --all` — короткие ключи (`PLN-3`);
- `herdr-projects details <id>` — по запросу: вердикт, проверки, ветка, worktree,
  план, попытки, `after`, лимиты;
- `herdr-projects after <id>` — что задача ждёт (опрос при каждом обновлении,
  кеш; при > 24 задач — раз в 3 обновления, после `after`/`delegate` — сразу);
- `herdr-projects show --task <id>` — модель агента.

| Статус | Действия |
|---|---|
| `waiting` | ответить (`tell`), разрешение/запрет, `stop` |
| `failed` | `retry`, `fix`, `finish`, `stop` |
| `ready` | «Одобрить» (2 клика) (`approve`), «Всё равно влить» (`approve --anyway`), `review` |
| `plan` | «Одобрить план» (2 клика) |
| `review` | `tell`, `stop` |
| `working` | `tell`, `stop` |
| `queued` | «Запустить сейчас» (`delegate --now`) |
| `done` | в архив (`archive`) |

**Одобрение всегда требует подтверждения**: первый клик взводит кнопку, второй —
отправляет. Подтверждение своё у задачи и действия; двойной клик не считается
(второй клик раньше 600 мс игнорируется). Сервер тоже отказывает
`approve`/`anyway` без `confirm: true`.

Остальные действия: «Написать агенту» (`tell <id> -- <текст>`), «Вернуть ревью»
(`review`), «Остановить» (`stop`), «Исправить ошибку» (`fix`), «Завершить как
есть» (`finish`).

### Архив

«Архив» в HUD открывает список; «Вернуть» — `restore`. «Убрать сделанные» —
`archive` для всех сделанных. Всё это команды доски; своего архива нет.

### Файлы: yazi

Кнопка папки открывает worktree в **yazi** (`xdg-terminal-exec yazi <папка>`);
в «Фокусе» есть «Отчёты» (`~/.herdr-projects/reports/<repo>/<номер>`). На
удалённой странице кнопка показывает путь: файлы открываются только на машине с
доской.

## Доступ с другой машины: логин и пароль

По умолчанию служба слушает `127.0.0.1` и не требует входа. Чтобы открыть с
другой машины:

```sh
scripts/install.sh password --listen 0.0.0.0 --user me
```

Команда спрашивает пароль дважды, считает **Argon2id-хеш** (bcrypt тоже
принимается через `set-auth`) и пишет в `~/.config/herdr-planner/config.toml`
только хеш (права `600`).

- Всё API за входом: без сессии `/api/*` отвечает `401`, `/` ведёт на `/login`.
- Сессия — случайный токен в cookie `HttpOnly; Secure; SameSite=Strict; Path=/`.
- После 5 неудачных попыток за 5 минут адрес блокируется на 5 минут (`429`).
- CSP запрещает внешние скрипты и стили; three.js отдаётся со своего origin.

### HTTPS

Cookie помечена `Secure`, поэтому для прямого доступа по IP включите TLS:

```sh
scripts/install.sh tls --cert /path/fullchain.pem --key /path/privkey.pem
```

Можно поставить TLS-прокси или Tailscale Serve; прокси должен передавать
`X-Forwarded-For` — по нему считаются неудачные входы и видно, что клиент
удалённый (тогда yazi не открывается, а показывается путь).

## Упрощённый режим и слабое железо

Включается `prefers-reduced-motion: reduce`, `?calm`, переключателем в HUD или
сам, если первые 3 секунды медиана кадра хуже 33 мс (с тостом «вернуть»). Тогда:
`pixelRatio` 1, без атмосфер, пульсаций и твинов, орбиты стоят, звёзд меньше,
кадр рисуется по требованию. Смысл статусов сохраняется.

Без WebGL канвас скрыт, открыт навигатор мира; панели, запросы и действия
работают.

## Конфигурация

`~/.config/herdr-planner/config.toml` (все ключи необязательны):

```toml
listen = "127.0.0.1"
port = 7117
data = "~/.herdr-projects/data"
user = "me"
password_hash = "$argon2id$…"
tls_cert = "/path/fullchain.pem"
tls_key  = "/path/privkey.pem"
```

Приоритет: аргументы `--listen/--port/--data`, затем переменные
`HERDR_PLANNER_LISTEN`, `HERDR_PLANNER_PORT`, `HERDR_PROJECTS_DATA_DIR`, затем
конфиг. `HERDR_PROJECTS_BIN` задаёт путь к `herdr-projects`, `HERDR_BIN` — к
`herdr` (для проверок).

Служебные команды:

```sh
herdr-planner hash-password < password.txt
herdr-planner set-auth --user me --listen 0.0.0.0 < hash.txt
herdr-planner set-tls --cert fullchain.pem --key privkey.pem
```

## Проверки

```sh
scripts/run-checks.sh [каталог-для-снимков]
```

1. `cargo test` — разбор `list`, восемь статусов, проекты и итоги, `details`
   (включая попытки), `after` (теги, `(done)`, `nothing`, `far`), `valid_ref`,
   `valid_letter`, диалог Координатора, ключи `send-keys`, имена агентов, дела
   божьи, журнал, тема, входы, cookie, X-Forwarded-For, TLS-пути.
2. `scripts/check-install.sh` — установка/удаление во временном HOME, права
   конфига, служба, значок.
3. `scripts/check-open.sh` — окно-приложение по app-id, HTTPS/порт/адрес.
4. `scripts/ui-check.mjs` — headless Chromium с WebGL (SwiftShader):
   планеты/статусы/вселенные/связи из фикстуры, подписи, подлёты и «Фокус»,
   approve/anyway с подтверждением, `retry`/`tell`/`pick`/`fix`/`finish`,
   разрешение с заготовкой, рисование связи и отказы доски, снятие и «Отменить»,
   варианты и диалог Координатора через заглушку herdr, дела божьи (добавить,
   перетащить в вселенную → `add`, править, убрать), yazi и удалённый клиент
   (только путь), архив/restore, смена темы без перезагрузки, `?calm`, узкий
   экран (канвас во весь экран, чат и дела пристыкованы), ноль ошибок консоли.
5. `scripts/auth-check.mjs` — `401`, `/login`, cookie, вход из браузера, лимит,
   logout, безопасный `next`, отказ HTTP с удалённого адреса.

Сборка проверок идёт в `~/.cache/herdr-planner/target`.

## Устройство

```
src/main.rs         запуск, CLI, HTTP/HTTPS, опрос
src/config.rs       конфиг, Argon2/bcrypt, права файла
src/auth.rs         вход, сессии, лимит попыток
src/board.rs        list/details/after → задачи, ссылки, статусы, проекты
src/theme.rs        colors.toml → CSS-переменные
src/coordinator.rs  разбор coordinator, признак диалога
src/app.rs          снимок, журнал, кеш деталей и ожиданий
src/server.rs       маршруты, действия, чат, yazi, herdr, дела божьи
web/app.js          оркестратор: данные, панели, запросы, действия
web/world.js        сцена three.js: Бог, вселенные, планеты, связи, подписи
web/layout.js       детерминированная раскладка
web/camera.js       OrbitControls, подлёты
web/requests.js     сбор запросов к человеку, варианты ответа
web/vendor/         three.js 0.186.1 (MIT, локально)
packaging/          systemd, .desktop, значок, QML-виджет панели
scripts/            install, open, checks, fixture
```

Своей базы нет. Журнал — наблюдённые смены статусов, хранится в
`~/.local/state/herdr-planner/journal.json`; дела божьи — в `todo.json`; чат — в
`chat.json`. Свежая «сделано» живёт планетой 9 секунд, затем уходит на пояс.

## Ограничения

- Вкладки herdr-gpui и переход в пространство недоступны: это отдельное
  приложение.
- Последний ответ Координатора — хвост его окна, а не структурное сообщение.
- Содержимое диалога на экране агента доступно только при запущенном herdr.
- Кнопки разрешений шлют заготовленный текст через `tell`: у доски нет отдельной
  команды «разрешить» для задачи.
- На удалённой машине yazi не открывается — показывается путь.
- Задачи создаются Координатором (чат), `herdr-projects add` или делом божьим,
  перетащенным во вселенную.
