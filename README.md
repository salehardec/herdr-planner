# Herdr Planner — Галактика

Дашборд доски **herdr-projects** как трёхмерная **Галактика**, по которой летает
корабль оператора. Работает сам по себе: herdr (TUI) и herdr-gpui не нужны, данные
и команды идут напрямую в `herdr-projects`.

```
                     ·  туманность (проект)  ·
              планеты — задачи, спутники — субагенты
                    ╲                      ╱
 далёкая галактика ·  ◉ Квазар · Координатор  ·  далёкая галактика
  (другая машина)     ╱                      ╲   (другая машина)
```

- **Галактика** — вся доска этой машины. Другие машины доски (`herdr-projects
  machines`, `herdr machine list`) — **далёкие галактики** со своими Квазарами;
  перелёт к ним = подключение по SSH.
- **Квазар** — Координатор в центре: неоновый шар, джеты — его речь, кольца вокруг
  — лимиты подписок. Под ним — его субагенты-спутники и память (шкала контекста).
- **Туманность** — проект (git-репозиторий на доске). Папки проектов — рукава
  спирали; тихие проекты — дальше и меньше.
- **Планета** — задача. Основной агент задачи — кольцо-ангар вокруг планеты
  (форма метки — по программе), **субагенты** — спутники: живые, пока работают.
- **Корабль** виден от третьего лица; в ручном полёте — нос корабля внизу.
  Границу Галактики не пересечь: корабль мягко разворачивается.

## Управление

Выбери цель в **навигаторе** (`N`) или найди её **поиском** (`Ctrl+K`) — корабль
сам прилетит (разгон → варп → торможение) и выберет её. **Esc — ровно один шаг
назад**, как «назад» в браузере: закрыть панель → выйти из «Фокуса» → из туманности.

| Клавиши | Что делают |
|---|---|
| `Ctrl+K` | космический поиск (всегда вверху) |
| `P` | автопилот ⇄ ручной полёт |
| `N` / `F` / `T` / `J` / `R` | навигатор / фокус / дела / журнал / архив |
| `B` | «Ждёт тебя»: очередь запросов |
| `/` | чат с Координатором |
| `H` | домой · `0`/`Home` — общий вид |
| `Enter` | подлететь к выбранному |
| `Tab` / `Shift+Tab` | следующая / предыдущая планета по срочности |
| `[` / `]` | предыдущая / следующая туманность |
| `1–9` | N-й запрос из «Ждёт тебя» |
| `L` / `Shift`+тяни | связь `after` рисованием |
| `Q` | лимиты подписок |
| `?` | подсказка · `Esc` — шаг назад |

**Ручной полёт** (`P`, как в игре): `W A S D` (или стрелки) — вперёд/назад/вбок,
`Space` / `C` — вверх/вниз, `Shift` — форсаж, колесо — круизная скорость, мышь —
курс. Клик по пустому месту захватывает мышь (pointer lock), `Esc` отпускает.
Наведи прицел на туманность, планету, спутник, Квазар или далёкую галактику и
кликни (или удержи) — корабль **ныряет** в неё. Отклик мгновенный, инерция ≈ 0,1 с
только для плавности; чувствительность и инверсия — в меню. Горизонт выравнивается
сам. Буквы читаются по физической клавише — в любой раскладке.

**Автопилот**: мышь вращает обзор вокруг цели, колесо — ближе/дальше, клик по
вещи — перелёт к ней. Камера не «улетает»: у каждого уровня свои пределы.

### Принцип «не улетать от места действия»

Действие (одобрить, ответить, связать, перенести дело, добавить вселенную) оставляет
вас там же. А вот то, что вы **сами** перелетели (навигатор, поиск, клик, ключ
задачи в чате, ручной полёт), кладётся в стек: `Esc` возвращает туда, откуда вы
улетели, — с камерой, панелями, прокруткой и выделением. «Ждёт тебя» — очередь:
из списка вы проваливаетесь в запрос; после действия или `Esc` вас возвращает в
этот же список, обработанный запрос вычеркнут, курсор на следующем.

## Что внутри кабины

- **Навигатор**: Галактика (своя первой, далёкие ниже) → Туманность → задачи,
  сгруппированные по дате создания («Сегодня» открыта, затем `dd.mm.yyyy`, новые
  сверху) → спутники. Квазар — отдельный пункт; тихие туманности свёрнуты в одну
  группу. Стрелки, `Enter`, `aria-expanded`; без WebGL это главный вид.
- **Поиск**: галактики, Квазар, туманности (имя, ключ), планеты (ключ, заголовок,
  описание, строка доски, агент/модель, статус), спутники, дела и сообщения чата.
  Нечёткий (опечатки, `е`/`ё`, не та раскладка), группы с иконками, подсветка, путь
  `Галактика › Туманность › Планета`, статус цветом. Выбор — перелёт; сообщение чата —
  прокрутка к нему. Мгновенный клиентский индекс (uFuzzy) + полнотекстовый `GET
  /api/search` (SQLite FTS5, триграммы — работает для русского).
- **Чат с Координатором**: три последних вопроса и ответа, выше — подгрузка
  прокруткой (из стенограммы его сессии), **поиск по чату**, «↓ к последним»,
  крупный читаемый шрифт, картинки из буфера. Под названием — **память
  Координатора** (заполненность контекста, жёлтый > 70 %, красный > 90 %) и две
  кнопки: **Compact** (`/compact`) и **New** (`coordinator new`), обе с
  подтверждением; то же для далёких Координаторов (Compact через `dispatch`).
- **Дела**: кнопка выдвигает список (анимация GSAP). Дело можно адресовать
  Координатору или агенту задачи; перетащить на **планету** (`tell`), на
  **Квазар** (`coordinator tell`) или на **туманность** (новая задача:
  проект, программа, модель — текстом или из списка `herdr-projects models`);
  порядок — перетаскиванием или `Alt+↑↓`.
- **Фокус**: запрос к человеку и ответы (разрешение, план, попытки, диалог на экране
  агента, ревью), **«Итог агента»** (`closing.md`), описание, субагенты, связи.
  Текст не на языке интерфейса — кнопка **«Перевести»** (модель на сервере, без
  инструментов, ключей в браузере нет).
- **Канбан-строка** «Очередь · План и работа · Ревью · К одобрению · Сделано» —
  счётчики и фильтр мира.
- **Субагенты** — спутники планеты и пункты навигатора; карточка: роль, что делает,
  сколько идёт, итог. Источники: claude — `~/.claude/projects/…/<сессия>/subagents/`,
  omp — дочерние файлы сессии, codex — потоки с `parent_thread_id`; у pi их нет
  («нет данных»). Состояния: идёт / затих / завершён (флаги `finished` ненадёжны —
  правила по содержимому и свежести).

### Далёкие галактики

Машины доски (`herdr-projects machines`, `herdr machine list`) — это SSH-хосты;
доска сама ходит к ним тем же login-shell-способом, и планировщик берёт этот
механизм. Перелёт к далёкой галактике — подключение: «устанавливаю связь…», «на связи
· herdr-projects 1.2.4», «нет связи: причина» (и что сделать; приземлиться нельзя).
Дальше **все действия идут туда**: чат (`remote dispatch`), `tell`/`approve`/`pick`/…
(`remote do`), связи `after` (по SSH). Ключи и пароли SSH планировщик не хранит и не
спрашивает — только ssh-agent и конфиг пользователя на машине службы. Добавить машину —
из навигатора (`herdr machine add <цель> --label <метка>` открывается в терминале для
подтверждения).

Одинаковые проекты (один `origin`) в разных галактиках связаны **мостом**; клон,
отставший по главной ветке, помечен «main −N», карточка туманности показывает таблицу
клонов и **«Предложить обновить»** (задача на доске той машины; в чужих чекаутах
планировщик ничего не меняет сам, показывает и команду).

### Добавить туманность (проект)

Из навигатора: папка с git (автодополнение пути) или адрес репозитория. Хостинг —
GitHub (`gh`), GitLab.com и свой GitLab (`glab`, тот хост, где вы вошли; не вошли —
понятная подсказка). Право записи проверяется у хостинга. **Своё** — клон в `~/Projects`
(или `projects_dir`), **чужое, хочу менять** — форк (`origin` = форк, `upstream` =
оригинал; «подтянуть», «PR/MR в оригинал», «отставание от upstream»), **чужое,
изучать** — клон без записи (`research.only true`, «превратить в форк»). Для GitLab
ставятся `merge.pr false` и `merge.checks none` (доска открывает PR только на GitHub).
Регистрация — тем способом, каким доска узнаёт репо (`herdr-projects add … --repo`),
с подтверждением и прогрессом.

## Установка

Сейчас — из клона репозитория (первого релиза ещё нет; сборка бинарника — `cargo`, страница — `scripts/web-build.sh`):

```sh
git clone https://github.com/salehardec/herdr-planner && cd herdr-planner
scripts/install.sh --from-source
```

Когда выйдет первый релиз (его собирает `.github/workflows/release.yml` по тегу `v*`; пробный — `v0.4.0-rc1`),
ставить можно будет одной строкой — **эта команда заработает только после первого релиза, до него она отвечает 404**:

```sh
curl -fsSL https://github.com/salehardec/herdr-planner/releases/latest/download/install.sh | sh
```

Скрипт идемпотентен (повторный запуск обновляет), печатает шаги `[1/7] …`, понимает
`--dry-run`, `status`, `uninstall` и ставит **всё**: herdr (mise), плагин herdr-projects,
сам планировщик (готовый бинарник релиза, без сборки; `--from-source` — сборка из клона), службу `systemd --user` (macOS —
launchd), значок и окно (Omarchy). Arch/Omarchy, Debian/Ubuntu; macOS — по возможности.
Логин, пароль и адрес — вопросом или флагами (`--user`, `--password-stdin`, `--listen`).
После установки на новой машине — подсказка, как сделать её далёкой галактикой другой:
`herdr machine add <user>@<хост> --label <хост>`. Из клона репозитория:

```sh
scripts/install.sh            # из исходников: --from-source
scripts/install.sh status
scripts/install.sh uninstall
```

Состояние — `~/.local/state/herdr-planner` (SQLite, картинки чата), конфиг —
`~/.config/herdr-planner/config.toml` — при удалении сохраняются. Без пароля служба
слушает только `127.0.0.1:7117`.

### Окно-приложение

Значок в панели Omarchy и ярлык открывают **отдельное окно** (Chromium app window,
1280×940), а не вкладку; окно опознаётся по app-id в отдельном профиле.

## Сборка и стек

- **Сервер**: Rust + axum + tokio, один бинарник; **SQLite** (`rusqlite`, WAL) —
  дела, журнал, история статусов, индекс чата, поиск FTS5 (триграммы), кэш далёких
  галактик и отставания, переводы; кэш в памяти (`moka`); живые обновления по **SSE**
  (`GET /api/events`), изменения доски — по слежению за файлами (`notify`: `task.json`,
  `closing.md`, состояние Координатора, стенограмма, лимиты, тема), страховочный опрос
  раз в минуту. Без Postgres, Redis, Docker и Electron.
- **Страница**: TypeScript + Vite, **three.js** + **postprocessing** (bloom для неона),
  туманности — частицы на шейдерах (один draw call), планеты/спутники/кольца —
  `InstancedMesh`, подписи — DOM только у ближних и выбранных; **GSAP**, **uFuzzy**,
  **Preact** + `@preact/signals`, нативный drag&drop. Сборка вшита в бинарник
  (`rust-embed`).

```sh
scripts/web-build.sh          # страница → ~/.cache/herdr-planner/web/dist (сборка вне репо: NTFS)
scripts/web-build.sh --test   # vitest
cargo build --release         # бинарник со страницей внутри (CARGO_TARGET_DIR вне репо)
```

Сборка идёт в копии `~/.cache/herdr-planner/web/src-copy`: на NTFS нативные
esbuild/rollup не запускаются. `build.rs` ищет страницу в `$HERDR_PLANNER_DIST`, затем в
кэше, затем в `web/dist`.

## Упрощённый режим и слабое железо

`prefers-reduced-motion: reduce`, `?calm`, переключатель в меню или авто (если медиана
кадра хуже 40 мс, с тостом «вернуть»): `pixelRatio` 1, без bloom и движения частиц, 150
точек на туманность, перелёты мгновенные (затемнение 150 мс), панели непрозрачные,
кадр рисуется по требованию. Смысл статусов сохраняется. Без WebGL канвас скрыт,
навигатор открыт, поиск и все действия работают. На 50 туманностях / 500 планетах —
LOD частиц по экранному размеру, подписи не больше 24 без наложений.

## Доступ с другой машины: логин и пароль

По умолчанию служба слушает `127.0.0.1` без входа. Чтобы открыть с другой машины:

```sh
scripts/install.sh password --listen 0.0.0.0 --user me
```

Хеш **Argon2id** в `config.toml` (права `600`), сессия — cookie `HttpOnly; Secure;
SameSite=Strict`, после 5 неудачных попыток за 5 минут адрес блокируется. Всё API и поток
событий — за входом. Для прямого доступа по IP включите TLS (`scripts/install.sh tls
--cert … --key …`) или поставьте TLS-прокси / Tailscale Serve (он должен передавать
`X-Forwarded-For`). HTTPS через Tailscale-сертификат — отдельной задачей позже; место
под него есть (`tls_cert`/`tls_key`, доверенный прокси).

## Конфигурация

`~/.config/herdr-planner/config.toml` (все ключи необязательны):

```toml
listen = "127.0.0.1"
port = 7117
data = "~/.herdr-projects/data"
user = "me"
password_hash = "$argon2id$…"
tls_cert = "/path/fullchain.pem"
tls_key  = "/path/privkey.pem"
translator = "claude/claude-haiku-5-5"   # или omp/<модель>; кто переводит ответы агентов
projects_dir = "~/Projects"              # куда клонируется репозиторий, добавленный адресом
ssh_bin = "ssh"
```

Приоритет: аргументы `--listen/--port/--data`, затем `HERDR_PLANNER_LISTEN`,
`HERDR_PLANNER_PORT`, `HERDR_PROJECTS_DATA_DIR`, затем конфиг. `HERDR_PROJECTS_BIN`,
`HERDR_BIN`, `HERDR_PLANNER_SSH`, `HERDR_PLANNER_CLAUDE`, `HERDR_PLANNER_GH/GLAB`,
`HERDR_PLANNER_TERMINAL` подменяют программы (для проверок).

## API (за входом)

`GET /api/state`, `GET /api/events` (SSE: `state`, `chat`, `progress`), `GET /api/details`,
`GET /api/task/closing`, `GET /api/subagent`, `GET /api/search`, `GET /api/models`,
`GET /api/chat/history` (`before`, `q`), `POST /api/chat`, `POST /api/chat/attach`,
`POST /api/action` (с `galaxy` — на другую машину), `POST /api/translate`,
`POST /api/galaxy/ask`, `POST /api/galaxy/add`, `GET /api/fs/complete`,
`POST /api/universe/{inspect,add,fork}`, `GET /api/universe/info`, `POST /api/refresh`,
`POST /api/logout`; без входа только loopback-виджет `GET /api/limits`.

## Проверки

```sh
scripts/run-checks.sh [каталог-для-снимков]
```

`npm test` (vitest: раскладка на 50/500, полёт и граница, навигатор по датам, поиск,
i18n), `cargo test`, установщик во временном HOME (`scripts/check-install.sh`),
окно-приложение, затем страница в headless Chromium на фикстуре
(`scripts/fixture.mjs` — поддельные `herdr-projects`, `herdr`, `ssh`, `claude`, `gh`,
два git-репо с отставанием) и вход по паролю (`scripts/auth-check.mjs`).
Фикстура `--scale 50x500` проверяет плавность большого мира.
