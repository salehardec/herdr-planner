# Комната отдыха · макет для одобрения (PLN-13 → PLN-9)

Живой макет места на корабле из Галактики (`design/galaxy/`). Тестовые данные, без сервера, всё нарисовано в файле (SVG/canvas), внешних CDN нет.

Открыть: `design/restroom/restroom.html` в браузере. Параметры: `?room` — сразу в комнате, `&theme=light` — светлая тема.

**В Галактике:** комната встроена в `design/galaxy/galaxy.html` — клавиша `O`, кнопка «☕ Отдых» в верхней строке,
«Корабль → Комната отдыха» внизу навигатора, Tweaks → экран «18 · Комната отдыха». Галактика открывает `restroom.html?embed`
в постоянном слое-iframe (кабина и Tweaks комнаты скрыты, цвета темы Omarchy передаются из галактики), а «Лететь»
выбирает настоящую задачу галактики (ALP-16, PRT-16). Нужен http-сервер (`python3 -m http.server` в `design/`).
Справа внизу — **Tweaks** (только для макета): тема, «ещё уведомление».

## Где вызывать

| Место | Почему |
|---|---|
| **Люк в кабине** (левый нижний угол, у пола) | Физическое место на корабле: дверь отсека, при наведении створки приоткрываются |
| **Навигатор → раздел «Корабль» → «Комната отдыха»** | Корабль — отдельная ветка рядом с Галактикой; туда же лягут будущие отсеки |
| **Клавиша `O`** (и `Щ` в русской раскладке), кнопка «☕ Отдых» в верхней строке | `O` в галактике свободна (заняты p, h, n, f, t, b, /, 0) |

**Вход и выход** — анимация шлюза: створки сходятся с подписью «ШЛЮЗ · КОМНАТА ОТДЫХА», за ними сцена меняется, створки расходятся.
**Выход** — `Esc` или «← Назад в …»: возвращает ровно туда, откуда пришёл (кабина с тем же фокусом, или навигатор); подпись кнопки называет это место.
При выходе игра встаёт на паузу и ждёт: при новом входе — та же игра на паузе (`P` — продолжить), счёт и волна на месте.

## Обои

Панель слева внизу, сворачивается кнопкой «–» (на экранах уже 1500 px свёрнута сразу и раскрывается сеткой 2×2, чтобы не заходить на приставку). Клик мышью по кнопке панели не оставляет на ней фокус — Пробел и Enter идут в игру. Выбор запоминается (localStorage), включая свою картинку.

1. **Земля + сад** (по умолчанию) — оранжерея корабля: арочная рама, грядки, лианы, за стеклом восход Земли.
2. **Море** — закат над морем через иллюминатор.
3. **Сияние** — северное сияние над хвойным лесом (предложение для третьего).
4. **Обзор…** — своя картинка (FileReader → data URL), появляется плитка «Свои» с превью.

Обои медленно «дышат» (масштаб 1→1.04 за минуту); при `prefers-reduced-motion` — неподвижны.

## Приставка «Звёздный Досуг»

Ретро-консоль по центру, вписывается между панелями и по высоте окна: экран 240×224 (почти квадратный, выше прежнего) с пиксельной графикой и строками развёртки, крестовина, A/B, «МЕНЮ»/«СТАРТ», динамик. Кнопки корпуса нажимаются мышью/пальцем.

Меню: `↑↓` выбор, `Пробел`/`Enter` старт.

**Звёздный заслон** (своя игра про корабль и пришельцев, играбельная):
- `←→` / `A D` — движение, `Пробел` — огонь, `P` — пауза, `M` — меню, `Esc` — выйти из комнаты (пауза);
- счёт, 3 жизни (неуязвимость после попадания), волны ускоряются, «ИГРА ОКОНЧЕНА» → новое нажатие `Пробел` заново (зажатый Пробел не перезапускает, счёт успеваешь увидеть).

**Кирпичики** (тетрис-подобная, тоже работает в простом виде): `←→↓`, `↑` поворот, `Пробел` сброс, счёт и линии.

Потеря фокуса окна ставит игру на паузу.

## Уведомления

Правый верхний угол, из «Ждёт тебя». В макете два приходят через 4 и 11 с после входа:
- «Ждёт тебя · вопрос агента» (ALP-16, жёлтый),
- «Готово к одобрению» (PRT-16, PR #41, пурпурный).

Кнопки: **«Позже»** — убрать; **«Лететь →»** — игра на паузе, шлюз «ПЕРЕЛЁТ · ALP-16»; в Галактике — перелёт к планете задачи с фокусом, в отдельном макете — кабина фокус на этой сущности с действием («Ответить»/«Одобрить») и кнопкой «Обратно к игре (пауза)».

## Темы и движение

Интерфейсные панели берут токены Omarchy из `design/galaxy` (тёмная по умолчанию, светлая — Catppuccin Latte). Приставка и обои от темы не зависят — это «предметы» в комнате.
`prefers-reduced-motion`: без шлюза (мгновенная смена), без дрейфа обоев и выезда уведомлений.

## Что взять в реализацию

- Комната — отдельный экран-слой поверх мира (мир не выгружается, корабль стоит), состояние «откуда пришёл» хранить при входе.
- Обои — набор статических картинок в плагине (SVG из макета можно взять как есть) + свой файл в настройках; тема их не трогает.
- Игры — отдельный модуль на canvas с фиксированным шагом 60 Гц и API `pause()/resume()`; рекорды — в локальное хранилище.
- Уведомления — та же лента «Ждёт тебя», показывать только новые с момента входа; «Лететь» = пауза + выход + перелёт к сущности обычным путём галактики.
- Клавиши игры перехватывать только пока комната открыта; `Esc` всегда выводит.
