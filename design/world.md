# Herdr Planner — Галактика (мир)

Этот документ — как образ стал интерфейсом. Макеты, которые одобрил человек, — в
[`design/galaxy/`](galaxy/README.md); где макет и план расходились, сделано по макету.

```
   [Галактика orion]
        ◉ Квазар · Координатор
   туманности по рукавам спирали (папка проектов = рукав)
     ├─ alpha  ·  планеты-задачи ○ ○ ○   кольцо-ангар = основной агент
     │                            └─ спутники = субагенты
     └─ тихие туманности — внешнее кольцо, меньше и тусклее
```

## Слои

1. **WebGL** (`web/src/world/`) — вся сцена: фон и диск Галактики с рукавами, Квазар,
   туманности, планеты, спутники, связи, корабль, граница. three.js 0.186,
   `postprocessing` (bloom на Квазар, джеты, двигатель и неон; в упрощённом режиме и в
   светлой теме — выключен).
2. **Подписи** (`labels.ts`) — обычный DOM, не больше 24, по приоритету и без
   наложений; полная карточка — у выбранной и наведённой планеты.
3. **Панели Preact** (`web/src/ui/`) — навигатор, поиск, чат, дела, фокус, канбан,
   «Ждёт тебя», журнал, лимиты, диалоги. Все действия — кнопки DOM: подтверждения,
   доступность и клавиатура работают как раньше.
4. **Кабина** (`Cockpit.tsx`) — рамка вида, показанная, пока выбрана цель или корабль
   ведётся рукой: уголки, распорки, строка «цель · дистанция · скорость».

## Образ

| Сущность доски | Образ | Как рисуется |
|---|---|---|
| машина доски | галактика | диск со спиральными рукавами; чужие — далёкие спирали по кольцу за границей |
| раннер (машина с Docker) | верфь | кольцо-док с перекладинами сразу за границей Галактики |
| Координатор | **Квазар** | неоновый шар (шейдер Френеля), ореол, два джета (речь), кольца — лимиты подписок |
| его субагенты | спутники Квазара | мелкие луны, тот же цвет программы |
| проект | туманность | один `Points` на все туманности, движение в вершинном шейдере |
| задача | планета | `InstancedMesh` + шейдер с минимумом экранного размера; ореол/кольцо по статусу |
| основной агент | кольцо-ангар | тор цвета программы, метка формы: сфера/куб/октаэдр/тетраэдр |
| субагент | спутник | идёт — с искрой-хвостом; затих — тусклый; завершён — гаснет за 0,8 с |
| `after` | связь | кривая с бегущим штрихом, стрелка у ждущей, искра от предшественника |
| один origin в двух галактиках | мост | дуга с подписью «main −N» |

Цвет статуса — из темы Omarchy, но статус различим и без цвета: значок, подпись, кольцо.

## Раскладка

Детерминированная (`world/layout.ts`, тесты на 50 проектов / 500 задач): проекты
группируются по папке репозитория — по рукаву на папку; внутри рукава самые занятые
ближе к центру; каждая туманность занимает первое свободное место (ничего не
налезает), тихие — на внешнем кольце. Граница Галактики растёт с числом проектов;
далёкие галактики — за ней; верфи — сразу за границей (радиус `bound() + 200`), не ближе 120 друг к другу.

## Движение

- **Автопилот** (`flight.ts`, `index.ts`): орбитальная камера вокруг цели (планеты
  движутся — камера следует), перелёт = разгон → варп (FOV 45→73, штрихи, виньетка) →
  торможение; длительность растёт с расстоянием. В упрощённом режиме и в скрытой
  вкладке — мгновенно.
- **Ручной полёт**: модель корабля (`stepShip`) — мгновенный отклик на клавиши, инерция
  0,1 с, автогоризонт (крен возвращается), тангаж ±83°, квазар «не пускает», граница
  мягко разворачивает. Захват мыши — по клику; прицел с конусом 3° и удержанием
  0,35 с — «нырок».
- **Уровни**: Галактика → туманность (облако прозрачнее, остальные гаснут) → далёкая
  галактика (мир другой машины).

## Стек навигации

`nav.ts`: кадр = выбор, камера, открытые панели, курсор «Ждёт тебя». Собственные
перемещения кладут кадр, `Esc` снимает ровно один; действия кадров не трогают. Из
«Ждёт тебя» запрос открывается поверх своего кадра и после действия возвращает в список.

## Доска → страница

`GET /api/events` (SSE) отдаёт снимок при изменении доски; файлы доски сторожит
`notify`. Снимок: задачи с датой создания, описанием, моделью, субагентами; проекты с
папкой, origin, отставанием; Координатор с памятью; далёкие галактики и мосты.

## Производительность

Планеты, кольца, метки форм, спутники — `InstancedMesh` (несколько draw call); туманности
— один `Points`, LOD частиц по экранному размеру (4 раза в секунду); подписи только
у ближних; bloom на половинном разрешении; упрощённый режим — по запросу, без bloom.
Включается автоматически, если медиана кадра хуже 40 мс.

## Чего нет

Внешних 3D-моделей, WebGPU, Postgres/Redis/Docker/Electron, хранения и запроса
SSH-ключей, других машин доски, фонового `git fetch/pull`.
