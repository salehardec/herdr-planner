# Галактика · макеты для одобрения (PLN-10 → PLN-9)

Живой макет нового мира из плана PLN-9 (версия 3). Тестовые данные, без сервера.

Открыть: `design/galaxy/galaxy.html` в браузере (или `python3 -m http.server` в этой папке).
Справа внизу — панель **Tweaks** (по умолчанию свёрнута, раскрыть кнопкой «–») (только для макета): переход к экранам, тема, упрощённый режим и варианты.
Параметры адреса: `?screen=N` — сразу открыть экран, `&theme=catppuccin-latte` — тема, `&instant` — без анимации
перелётов, `&tw` — свернуть Tweaks (по умолчанию свёрнута; раскрытие запоминается).

Сцена нарисована на Canvas 2D с перспективой — это показ образа и движения, не код продукта
(в продукте — three.js + bloom, туманности на шейдерах, GSAP, Preact по §4.0 плана).

## Темы и упрощённый режим

Темы Omarchy (значения из `colors.toml`): Americano Night, Tokyo Night (тёмные), Americano Day, Catppuccin Latte
(светлые). В светлых частицы рисуются обычным смешиванием вместо аддитивного. **Упрощённый режим**: сцена
неподвижна, туманности по 150 точек, перелёты мгновенные с затемнением 150 мс, панели непрозрачные, текст
навигатора и чата крупнее. `prefers-reduced-motion` отключает CSS-анимации.

## Отличия от плана

- **Экран агента и файлы в далёкой галактике доступны** (план §4.7 их исключал): «Экран агента» открывает локальный терминал с `herdr --remote <target> [--session <s>]` и фокусом на вкладку агента; «Файлы (yazi)» — терминал с `ssh -t <target> 'cd <worktree> && exec yazi'` (если yazi там нет — планировщик проверяет `command -v yazi`, ОС и менеджер пакетов и предлагает поставить: Linux и macOS, x86_64 и arm64: по `uname -sm` выбирается бинарник релиза (`yazi-{x86_64,aarch64}-unknown-linux-musl.zip`, `yazi-{aarch64,x86_64}-apple-darwin.zip`) в `~/.local/bin` без sudo — это путь по умолчанию. Менеджер пакетов предлагается, только если yazi есть в его репозиториях: Arch — `sudo pacman -S --needed yazi` (пароль sudo человек вводит сам в открывшемся терминале), macOS — `brew install yazi` (без sudo, по умолчанию при Homebrew); в Ubuntu/Debian пакета yazi нет — вариант выключен с объяснением. Все команды на той машине идут в login shell, той же формой, что у доски (`ssh <t> 'exec "${SHELL:-/bin/sh}" -lc "…"'`), иначе brew и `~/.local/bin` не в PATH. Планировщик запоминает, куда поставлен yazi, и открывает его по этому пути. С двухшаговым подтверждением и прогрессом). Картинки (PNG/JPG) в yazi по SSH: терминал открывается тот, что умеет графику (Linux: kitty — здесь первый в `xdg-terminal-exec`, ghostty, wezterm, foot; macOS: `open -a` kitty, Ghostty, WezTerm, iTerm2), yazi на той машине рисует их протоколом kitty через SSH; на той машине нужен только `file`; запасной вариант — `chafa` (символами), по желанию. Ключи — у ssh-agent, как у доски.

- Экран первого запуска (17) и нос корабля в ручном полёте — добавлены по просьбе человека; в плане их нет.

- **Туманности строятся по списку репо доски (`<data>/repos.json`, только чтение), а не только по задачам из `list`**: иначе вселенная без живых задач (только что добавленная, или все задачи в архиве) пропадает из мира и на неё нечего перетащить. Пустая вселенная — маленькая тусклая туманность на внешнем кольце с подписью «пусто — перетащи сюда дело»; репо, чьей папки больше нет, не показываются (в навигаторе — «папка не найдена», убрать с доски — командой доски, если она появится).

- Масштаб и добавление вселенных (экраны 13–16) — по сообщениям человека из описания PLN-9; в плане v3 их нет. Производительность сцены здесь — Canvas 2D: на 50/500 в headless Chromium без GPU кадр ≈ 14 мс снаружи и ≈ 7 мс внутри туманности; в продукте — three.js с инстансингом (один `Points` на туманность, `InstancedMesh` для планет), это нужно проверить на встроенной графике отдельно.
- Pointer lock: при захвате мыши вверху плашка «Esc — отпустить мышь»; при потере фокуса окна все клавиши отпускаются.

- **Ручной полёт переделан по отзыву человека** (план §4.2 описывал `A/D` как поворот, курс зажатой ЛКМ и автогоризонт): теперь `A/D` — стрейф, мышь с захватом курсора — обзор, `Space`/`C` — вертикаль, клик или удержание прицела — нырок; автогоризонта нет, тангаж задаёт мышь. В план PLN-9 это нужно перенести.

- Сцена в макете — Canvas 2D, не three.js; bloom, шейдеры и GSAP показаны приблизительно.
- В кабине панель подсказок скрыта (её место занимают навигатор и чат); подсказки снова видны снаружи и при
  переключении в ручной режим. В плане это не оговорено.
- В фокусе задачи добавлены кнопки «Сказать агенту / Экран агента / yazi» — это уже существующие действия.
- Далёкая галактика в макете показана упрощённо: лимиты подписок у её Координатора — те же, что дома.
- Канбан-строка видна и снаружи (в плане — в кабине; снаружи HUD-пайп). Предлагаю одну строку везде.
