# Дизайн Herdr Planner

- [`world.md`](world.md) — как устроена Галактика: образ, слои, раскладка, движение, стек навигации.
- [`galaxy/`](galaxy/README.md) — живые макеты Галактики (HTML, тестовые данные, без сервера): их одобрили до реализации.
- [`chat/`](chat/README.md) — макет нового вида чата Координатора (PLN-60): Markdown, события доски, уведомления, чипы задач, действия по наведению; варианты A/B/C на выбор.
- [`restroom/`](restroom/README.md) — макет «комнаты отдыха» на корабле. В продукт пока не вошёл.

Макеты — это показ образа и движения, а не код продукта: сцена в них нарисована на Canvas 2D. Где макет и
продукт расходятся, правда в продукте; актуальные снимки — в [`../docs/img/`](../docs/img/), их снимает
`scripts/readme-shots.mjs`.
